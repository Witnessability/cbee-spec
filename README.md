# Claim Boundaries for Execution Evidence (CBEE)

Editing home for the individual Internet-Draft `draft-sergeev-claim-boundaries`
by Mikhail Sergeev. Published baseline: **-02**.

- [Official document and history](https://datatracker.ietf.org/doc/draft-sergeev-claim-boundaries/)
- [Published -02](https://datatracker.ietf.org/doc/draft-sergeev-claim-boundaries/02/)
- [Working RFCXML](draft-sergeev-claim-boundaries.xml)
- [Frozen -02 XML/TXT and checksums](published/02/)
- [Contribution guidance](CONTRIBUTING.md)
- [Revision preparation and submission](PUBLICATION-PROCESS.md)

The root XML is the only editable manuscript source. The published/02 files are
frozen archival copies. Editorial changes here become an IETF revision only after
submission and posting. This is an individual document, not a WG adoption or an
IETF consensus statement. A repository merge does not imply contributor endorsement.

The initial working XML is byte-identical to the archived -02 XML. Render review
TXT/HTML with xml2rfc in a local build directory and record the exact formatter
version. The release process requires a current preflight and author decision.
No submission or release automation is enabled by this initial package.
