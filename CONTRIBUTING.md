# Contributing

Comments by issue, pull request or email to the author are welcome. A section
reference, question, counterexample or suggested wording is enough; GitHub use
is not required. Please read the [IETF Note Well](https://www.ietf.org/about/note-well/).
Contributions intended for the IETF are subject to the applicable BCP 78/79 obligations.

Discuss substantial changes with the editor and use a focused PR. Record the
reason, affected claims and relevant evidence. Edit the root RFCXML; preserve
archived published files. Generated renderings are not separate manuscript sources.
Respect the scope of contributor consent and preserve attribution. No additional
CLA or signed editorial form is introduced by this repository.

The IETF archive defines the posted document. Editorial merges do not establish
IETF consensus, proof of implementation behavior, or an authorization to submit.
